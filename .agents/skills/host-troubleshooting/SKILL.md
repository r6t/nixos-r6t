# Host Troubleshooting

Host-specific troubleshooting notes are private. If the private checkout has a
matching incident/runbook document, read it before proposing changes.

Distinguish recorded observations from hypotheses. Preserve known-good
mitigations and do not generalize host-specific findings to other machines
without evidence.

Do not run rebuild, activation, or destructive diagnostic commands. After flake edits, run `./format.fish`.
